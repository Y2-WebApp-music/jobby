# React + TypeScript + Vite + shadcn/ui

This is a template for a new Vite project with React, TypeScript, and shadcn/ui.

Install Dependencies

```bash
bun i
```

Development

```bash
bun dev
```

Format Code

```bash
bunx prettier . --write
```

### Docker Run

```bash
docker build -t jobby .
```

```bash
docker run -p 8080:80 jobby
```
